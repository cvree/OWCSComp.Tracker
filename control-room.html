Installed layouts

Layout editor —

Drag a box to move it, drag its corner to resize. Arrow keys nudge by one pixel, with Shift by ten. Saving takes a backup first and records the edit against your name.

Publishing

The public dataset the website renders. Every publish takes a verified backup first and replaces the file atomically, so a failure mid-write can never leave a half-written dataset on the site.

Put it on the website

Regenerates the public dataset and uploads it to the repository the site is built from. The site rebuilds itself a minute or two later. Nothing is uploaded unless it passes the same checks the local publish does, and the upload is read back afterwards to confirm what actually landed.

Shows up in the site's history. Blank is fine.
