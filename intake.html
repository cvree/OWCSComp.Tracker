Intake Review · one pasted link, every stage visible

What the machine proposed, and exactly what to run next.

With the local control room (python pipeline/serve.py) this page takes a pasted broadcast link and runs convert-link — ingest, download, layout, segmentation, identity proposals — to the first human gate, live. On static hosting it stays a read-only snapshot (generated by python pipeline/automation/cli.py intake-export --save) and every action is a command you run yourself. Either way nothing is approved or published automatically: proposed values are shown beside the values a human has confirmed, and only the confirmed ones are ever published.
