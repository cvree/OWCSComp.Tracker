Name the heroes

The tracker can only read a hero it has been shown. Each card below is one portrait it saw again and again on a real broadcast — the same hero, in the same look. Name it once and the tracker learns to read that hero by itself.

Nothing you name is trusted on your word alone: the tracker builds reference images from the card, then tests them on parts of the broadcast it never learned from. Only heroes it then reads correctly are kept.
