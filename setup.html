Let's get you processing broadcasts.

This takes about two minutes. Everything runs on this PC — there is no account to make, no server to pay for, and nothing to install by hand. Nothing you do here can be undone later from the control room.

What this app does

1 · You paste a link
A YouTube VOD or playlist, a FACEIT room, match or tournament, or a video file on this PC.
2 · It does the rest, in the background
Downloads the broadcast, works out the HUD layout by itself, tells gameplay apart from replays and desk segments, reads all ten hero portraits and tracks every swap across the map.
3 · Only proven results get published
A reading has to repeat, and clear a confidence floor, before it counts. Anything uncertain waits for you in a review inbox with the evidence attached.

Where the video goes

Broadcasts are large. The app keeps itself inside the budget you set here, and deletes only source video it has already finished with — never evidence, reports or results.

API keys optional

Both are optional — the app works without either. Keys are stored through Windows, encrypted for your Windows account only, and are never written to a settings file, a log, or anything the app publishes.

Running in the background

The processing service is separate from this window. Closing the control room never stops a job, and a reboot picks up exactly where it left off.

The real test

This builds a broadcast video on this PC and runs the whole pipeline over it — download bookkeeping, layout detection, gameplay segmentation, hero reading, clip extraction and export. It is the same end-to-end suite the project's own CI runs, not a simulation of one. It takes a few minutes.
