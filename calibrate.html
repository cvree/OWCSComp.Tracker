Teach the tracker a new broadcast

Every broadcast puts the hero portraits in a slightly different place. This finds them for you. It takes about two minutes, and everything happens inside this browser tab — your video is never uploaded anywhere.

1 · Add your broadcast

A video file works best. You can also drop in screenshots if you already have some.

I only have a YouTube link

A browser tab is not allowed to download from YouTube, so this page cannot take a link directly — but the screenshot route takes about a minute and works just as well.

  1. Open the VOD in a second tab.
  2. Scrub to a moment of live play — both teams' hero portraits along the top of the screen. Not the desk, not a replay, not a kill cam.
  3. Pause, then press PrtScn (Windows) or ⌘⇧4 then Space (Mac) to capture the window.
  4. Do that 4–6 times at different points in the map.
  5. Drag those images onto the box above.

Full screen is best, and any resolution is fine as long as every shot comes from the same broadcast — the tracker measures where the portraits sit as a fraction of the frame, not in pixels.

Or skip all of it: with the tracker running on your own machine, the pipeline downloads and calibrates the VOD itself from the link — how to run your own copy.

3 · Finding the hero portraits

Looking for the team colour chips along the top, fitting a grid to each team's five slots, then locating the portrait art. This runs on your computer, so it takes a few seconds.

4 · Does each box sit on a hero?

Ten boxes, five per team. Each one should sit squarely on a hero's portrait. Drag any box to move it, or drag its corner to resize. Moving one box moves its whole team's row together.

5 · Save your layout

This is a small text file describing where the heroes sit. Give it a name you'll recognise.

Letters, numbers and dashes. For example owcs-2026-stage3.

What to do with it

  1. Running the tracker from the source code? Move the downloaded file into the layouts/ folder inside the project — the one that already has owcs_youtube_2026.json in it. Nothing else to do: the layout resolver picks up every file in there on the next broadcast you convert.
  2. Using the desktop app? Open it, go to Calibration, and press Import a layout. Pick the file you just downloaded. That's it — it will use it on the next broadcast you paste in.
  3. Want it shipped with the tracker? Send it in — real calibrations for new broadcasts are the most useful thing anyone can contribute, and anyone may send one.
    So the layout can be credited to you.
    Opens a pre-filled submission with your layout in it. Nothing is sent until you press submit there, and you can read every line first.

One honest note. A layout made here is marked as browser-calibrated. It is a real measurement from your frames, but the full pipeline runs a stricter check over many more frames, so results from this layout go through review before they are published rather than being trusted automatically.
