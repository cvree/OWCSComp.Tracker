WHAT THIS APPLICATION DOES
--------------------------

It reads publicly broadcast Overwatch esports VODs and produces an auditable
record of which heroes each team played and when they swapped. Every claim it
publishes links back to the video frame and image crop it came from.

It runs entirely on this PC. There is no account, no subscription, and no
server. It sends no analytics or usage data anywhere.

NETWORK USE
-----------

The application makes network requests only when you ask it to:

  * downloading a broadcast you pasted a link to (YouTube),
  * reading match facts you pasted a link to (FACEIT),
  * checking for an application update, if you leave that enabled.

API keys you enter are encrypted for your Windows account and are never
written to logs, exports, or anything the application publishes.
